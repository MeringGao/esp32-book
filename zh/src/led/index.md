# LED 渐变效果

在本节中，我们将学习如何使用 ESP32 为 LED 创建渐变效果（即降低和增加亮度）。首先，我们将渐变板载 LED（onboard LED），它连接到 GPIO 2。

## 前置知识
要实现渐变效果，我们使用一种称为 PWM（脉冲宽度调制）的技术。

推荐阅读以下章节：
- [PWM 介绍](../core-concepts/pwm/index.md)
- [LEDC](../core-concepts/pwm/led-pwm-controller.md)

我们将逐渐增加 PWM 的占空比（duty cycle）来提高亮度，然后逐渐减少 PWM 占空比来降低 LED 的亮度。这样就有效地在 LED 上创建了渐变效果。

在 PWM 中，我们基本上设置一个百分比来指定每个周期中信号保持高电平（开启）和低电平（关闭）的时间。例如，在 50% 占空比下，信号一半时间开启，另一半时间关闭，使得 LED 只在半个周期内点亮。

现在，有趣的部分来了：当这种切换发生得非常快时，我们的眼睛跟不上。我们不会看到闪烁，而是觉得亮度在变化！LED 开启的时间越长，看起来就越亮；开启的时间越短，看起来就越暗。这就像是在欺骗你的大脑，让它以为 LED 在平滑地变暗或变亮。PWM：电子世界的魔术师！
