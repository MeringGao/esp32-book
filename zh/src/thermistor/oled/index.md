# 在 OLED 显示屏上显示温度

本章没有什么新内容。在大多数实际场景中，你不会连接到一个系统，而是希望将温度显示在类似 OLED 显示屏的设备上。因此，我们不再将温度打印到系统控制台，而是将其打印到 OLED 显示屏上。

我在上一章选择不使用 OLED 显示屏，是为了让你即使没有 OLED 也能完成热敏电阻的练习。但是，对于本次练习，你需要一个 OLED 显示屏。

## 前置条件

- 显然，你应该已经完成了前面关于热敏电阻的章节。
- [OLED 显示屏章节](../../oled/index.md)

我不会详细介绍代码，因为我们已经在前置条件部分解释过大部分内容了。

## 硬件需求

- 一个 OLED 显示屏：（0.96 英寸 I2C/IIC 4 引脚，128x64 分辨率，SSD1306 芯片）
- 跳线
- NTC 103 热敏电阻：10K 欧姆，5mm 环氧树脂涂层圆盘
- 10kΩ 电阻：与热敏电阻配合使用构成分压器

## 连接 OLED、热敏电阻与 ESP32 的电路

<img style="display: block; margin: auto;" alt="esp32 oled thermistor" src="../images/connectint esp32 oled thermistor.png"/>

### 将热敏电阻连接到 ESP32

这与我们在上一章使用的电路相同，所以你可以保持现有设置不变。

1. 热敏电阻的一侧连接到 `GND`。
2. 热敏电阻的另一侧连接到 `GPIO13`，这是 ESP32 的 ADC2 引脚
3. 一个 10kΩ 电阻与热敏电阻串联，在热敏电阻和 `3.3v` 之间构成分压器。所以将电阻的一侧连接到 `3.3V`，另一侧连接到 `GPIO13`

### 将 OLED 连接到 ESP32

我们将 GPIO 引脚 18 连接到 SCL，GPIO 引脚 23 连接到 SDA。OLED 的 VCC 引脚将连接到 ESP32 的 3.3V 引脚，接地引脚将连接到 ESP32 的接地端。
