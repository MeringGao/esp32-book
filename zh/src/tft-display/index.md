# TFT 显示屏（TFT Display）

在本章中，我们将学习如何使用 TFT 显示屏。TFT 代表薄膜晶体管（Thin-Film Transistor），它是一种 LCD（Liquid Crystal Display，液晶显示屏），为我们提供鲜艳的色彩、清晰的图像和快速的刷新率（refresh rate）。与简单的基于文字的显示屏（如 16x2 LCD 或单色 OLED）相比，TFT 显示屏允许我们显示全彩图形、形状、图像，甚至基于触摸的用户界面。

![2.8 英寸 TFT 显示屏](./images/tft-display-2.8-spi.png)

## 什么是 TFT 显示屏？

TFT 显示屏由排列成网格的数千个微小像素（pixel）组成。每个像素可以显示不同的颜色，允许我们在屏幕上绘制任何我们想要的内容。显示屏包含一个控制芯片（controller chip），用于理解来自我们微控制器的数据并相应地刷新屏幕。

TFT 显示屏在手机、智能手表和手持设备中非常常见。在嵌入式系统（embedded systems）中，它们用于构建仪表盘（dashboard）、游戏、控制面板等。

## TFT 显示屏的种类

TFT 模块有不同的尺寸、分辨率和通信类型。以下是一些常见的差异：

- 尺寸：从 1.3 英寸到 7 英寸或更大。

- 分辨率：从 128×160 到 800×480 及更高。

- 接口类型：TFT 显示屏提供不同的方式连接到微控制器。SPI（Serial Peripheral Interface）接口简单且使用较少的引脚，但速度较慢。并行接口（parallel interface）更快，但需要更多引脚。较大的显示屏通常使用 RGB（TTL）接口，它非常快但需要一个特殊的控制器才能工作。

## 我们的显示屏：2.8 英寸 SPI 触摸屏

在本项目中，我们将使用一个 2.8 英寸 TFT 显示模块，分辨率为 240×320 像素。它使用 SPI 接口，这使我们只需使用几个引脚即可将其连接到微控制器。

该模块还包括一个电阻式触摸屏（resistive touchscreen），它通过测量屏幕上的压力来检测触摸。我们将首先专注于在显示屏上绘制内容。

## 显示驱动（Display Driver / Controller Chip）

每个 TFT 显示屏都有一个控制芯片，负责在屏幕上绘制像素。在我们的例子中，显示屏使用 ILI9341 芯片。我们向这个芯片发送命令，它处理更新屏幕、绘制形状、填充颜色等任务。

ILI9341 控制器最常用于 2.4" 和 2.8" TFT 显示屏，有时也用于 3.2" 显示屏。如果你的屏幕使用相同的 ILI9341 芯片，它将与本教程中的相同代码和示例一起工作。

你也可以使用带有其他驱动芯片的显示屏（如 ST7735、ILI9225、ILI9486），但那些需要不同的 Rust crate 或设置说明。因此，在购买前检查显示屏中使用的控制芯片很重要，以确保它与教程兼容。

## 触摸控制器（Touch Controller）

一些 TFT 显示屏（如我们这里使用的）在屏幕顶部还带有电阻式触摸屏。在这些显示屏中，触摸功能由一个叫 XPT2046 的独立芯片处理。

这个芯片在你触摸屏幕时读取 X 和 Y 位置，并通过 SPI 发送该数据。它独立于显示驱动（ILI9341）工作。
