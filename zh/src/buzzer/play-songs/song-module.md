# 旋律示例：Pink Panther 主题曲（pink_panther.rs）

本节包含 Rust 模块 `pink_panther` 的代码片段。如果你想要其他歌曲/背景音乐的音符，可以参考 [Rust Embedded Songs](https://github.com/ImplFerris/rust-embedded-songs/) 仓库。

### 速度（Tempo）
我们声明歌曲的速度（tempo）（你也可以更改并观察结果）。

```rust
pub const TEMPO: u16 = 120;
```

## 旋律数组
